## ✨ Features (live v2)

- **Skills** — poster-card showcase of the working stack (Python, JavaScript, FastAPI, LangChain & RAG, React, HTML/CSS) with filters + toolbox strip.
- **Profiles** — live-synced GitHub card (avatar, stats, manual re-sync) plus an ID batch: LinkedIn, Hugging Face (15+ live AI tools), Instagram, Email.
- **Memory game** — 8-pair flip game with timer, move counter and best-score tracking.
- **Design** — intro loader, light & dark themes, page-wipe navigation, magnetic buttons, custom cursor ring, scroll progress rail.
